UP AND RUNNING IN A MINUTE

Install RanTube

The app checks your PC for yt-dlp. If it cannot find one, you can approve a separate copy from the official yt-dlp GitHub release. Then search videos or paste a link, inspect formats, and download to a folder you choose.

  1. 01
    Download the installer

    Choose Download for Windows above and wait for the .exe file to finish.

  2. 02
    Run the setup file

    Install for your Windows account. The installer does not need administrator access.

  3. 03
    Check your tools

    If yt-dlp is already on your PC, the app uses it. Otherwise, choose Set up to download the app's own copy. Internet access is needed for setup.

  4. 04
    Find and save media

    Search for a video, review its available formats, or paste a supported site link. Choose your save folder and start the download.

i

A note about formats and FFmpeg

Separate video and audio streams require FFmpeg to merge; combined formats do not. Audio-only formats download as audio files. Windows may show a SmartScreen warning because this installer is not code-signed.

RanTube

Downloads depend on the website and available formats. The app does not bypass DRM or access controls. Only download media you have permission to save.
